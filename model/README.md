# SysML v2 / MBSE Model Workspace

This directory is a text-first teaching workspace for systems modeling. It is organized around a small vehicle system so that each change can be reviewed as a focused Pull Request.

## Planned model slices

- `vehicle/vehicle.sysml`: system structure and interfaces.
- `vehicle/requirements.sysml`: requirements and satisfaction relationships.
- `vehicle/verification.sysml`: verification cases and traceability.

The files use SysML v2 textual notation inspired by the official SysML v2 Release examples. They are intentionally small and should be parsed with a compatible SysML v2 tool before being treated as authoritative engineering data.

## Collaboration boundary

GitHub stores the reviewable text representation, decision records, and validation scripts. A MagicDraw/Cameo + Teamwork Cloud environment remains the model repository when element-level locking, model history, permissions, and graphical views are required.
